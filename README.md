# Mukesh Reddy Theddu Portfolio

Welcome to the personal portfolio of Mukesh Reddy Theddu, a professional showcasing skills, projects, and contact information. This portfolio is built using React, Vite, TypeScript, and Tailwind CSS, designed with a classic and professional aesthetic.

## Features
- Responsive design that adapts to various screen sizes.
- Dark and light theme toggle for user preference.
- Detailed project showcase with descriptions and technologies used.
- Contact form for inquiries and social media links.

## Technologies Used
- **React**: JavaScript library for building user interfaces.
- **Vite**: Build tool that provides a fast development environment.
- **TypeScript**: Superset of JavaScript that adds static types.
- **Tailwind CSS**: Utility-first CSS framework for styling.

## Local Setup
To get started with the project locally, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/mukesh-reddy-theddu-portfolio.git
   ```
2. Navigate to the project directory:
   ```
   cd mukesh-reddy-theddu-portfolio
   ```
3. Install the dependencies:
   ```
   npm install
   ```

## Build Instructions
To build the project for production, run:
```
npm run build
```
This will create an optimized build in the `dist` directory.

## Testing
To run tests, use:
```
npm test
```
Make sure to write tests for your components and pages to ensure functionality.

## Deployment
This project is configured for deployment on Vercel. To deploy, follow these steps:

1. Push your changes to the main branch of your repository.
2. Go to [Vercel](https://vercel.com/) and import your GitHub repository.
3. Vercel will automatically build and deploy your project.

## Updating Content
To update the content of your portfolio:

- Modify the `src/pages/About.tsx` for personal information.
- Update `src/data/projects.ts` to add or edit project details.
- Change styles in `src/styles/index.css` or `tailwind.config.cjs` for design adjustments.
